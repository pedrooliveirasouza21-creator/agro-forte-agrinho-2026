# 🌱 Agro Forte Agrinho 2026

Website educativo sobre sustentabilidade agrícola, inovação tecnológica e desenvolvimento regional de **Itambaracá, Paraná**.

## 📌 Como Acessar o Site

### **Opção 1: GitHub Pages (Recomendado)**
Para ativar o GitHub Pages e ter um link direto do site:

1. Vá para **Settings** do repositório
2. Vá para **Pages** (no menu lateral esquerdo)
3. Em **Source**, selecione a branch: `website-development`
4. Selecione a pasta: `/ (root)`
5. Clique em **Save**
6. GitHub gerará um link como: `https://pedrooliveirasouza21-creator.github.io/agro-forte-agrinho-2026`

### **Opção 2: Abrir Localmente (Imediato)**
1. **Clone o repositório:**
```bash
git clone https://github.com/pedrooliveirasouza21-creator/agro-forte-agrinho-2026.git
```

2. **Navegue até a pasta:**
```bash
cd agro-forte-agrinho-2026
```

3. **Abra o arquivo `index.html` em seu navegador:**
   - Windows: Duplo clique em `index.html`
   - Mac/Linux: `open index.html` ou `firefox index.html`

### **Opção 3: Ver pelo GitHub (Visualização Rápida)**
1. Vá para a branch **website-development**: 
   - https://github.com/pedrooliveirasouza21-creator/agro-forte-agrinho-2026/tree/website-development
2. Clique em **index.html**
3. Clique no ícone **Raw** para ver o código
